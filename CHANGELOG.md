# Changelog

## 1.0.0

First release.

* 840 questions over 8 chapters (S1–S8), including the 2021-22 exam; 93 % verified by executing the
  code, the rest reviewed twice; correct answers spread evenly over a/b/c/d.
* A cheat-sheet lesson for every topic, with exam traps per chapter.
* Learn, Practice, Smart practice and Leitner review modes with instant feedback.
* Mock exam simulator: 40 questions, timer, sidebar, ANSWER / I DON'T KNOW, resume, results per
  chapter, retry mistakes; four variants.
* Progress page: mastery heatmap, estimated score, mock history, streak, confidence check.
* Offline-first PWA; optional Supabase sync (email + password) with an append-only, conflict-free log.
* Configurable scoring (negative marking, partial credit), JSON export / import, reset.
* Unit tests, browser tests and automatic verification + deployment on every push.
